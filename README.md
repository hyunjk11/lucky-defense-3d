# 🎲 운빨 디펜스 3D : 태초의 균열 (Lucky Defense 3D)

스타크래프트 인기 유즈맵 **'메운디(메이플 운빨 디펜스)'**에서 영감을 받아, 외부 에셋이나 CDN 없이 **Three.js 로컬 번들 + 순수 절차적 3D 모델링 + WebAudio 실시간 사운드 합성**으로 제작한 쿼터뷰 3D 전술 운빨 디펜스 웹 게임입니다.

---

## 🚀 로컬 실행 방법 (No-Build)

별도의 번들러나 패키지 설치 없이 바로 실행됩니다:

```bash
node serve.mjs
# 브라우저에서 http://localhost:8080/ 접속
```

유용한 쿼리 파라미터:
- `?autostart=1` 또는 `?test=1` : 메인 메뉴를 건너뛰고 즉시 1웨이브 시작
- `?seed=777` : 고정 시드 난수로 결정론적 뽑기/전투 재현

## ⚔️ 핵심 게임 규칙

1. **사각 순환 트랙 & 100마리 포화 한계**
   - 좌상단 차원 포털에서 스폰된 몬스터들은 중앙 6×6 성채 보드 둘레의 사각 트랙을 반시계 방향으로 순환합니다.
   - 트랙 위 살아있는 몬스터가 **100마리**에 도달하면 차원이 붕괴되어 즉시 패배합니다. (75마리 이상부터 경고 비네트 점멸)
2. **10라운드 챕터 보스 & 현상금 미션 보스 (`B`)**
   - 10, 20, 30, 40, 50 라운드마다 강력한 **챕터 보스**가 등장하며, **제한 시간(60초)** 내에 처치하지 못하면 패배합니다.
   - 쿨타임마다 직접 호출할 수 있는 **🎯 현상금 보스 (`B`)**를 제한 시간(40초) 내 처치하면 대량의 골드와 가스를 획득합니다.
3. **3대 공격 성향 × 몬스터 크기 상성**
   - **⚡ 속사·진동계 (`striker`)** : 초고속 단일 연사 & 치명타 특화 — **🐾 소형 적에게 150% 피해** (대형 65%)
   - **💥 중포·폭발계 (`destroyer`)** : 포물선 광역 폭발(Splash) & 방어력 파쇄 — **🐘 대형·보스에게 150% 피해** (소형 65%)
   - **🔮 마도·관통계 (`arcane`)** : 적 방어력 70% 무시 + 다중 연쇄 번개 + **이동속도 둔화(Slow) & 받는 피해 증폭** — **🛡️ 중형 128% 및 전 크기 시너지**
4. **7단계 등급 체계 & 태초(Primordial) 각성**
   - 등급: `일반(1)` → `희귀(2)` → `에픽(3)` → `유니크(4)` → `전설(5)` → `신화(6)` → **`🌌 태초(7)`**
   - **기본 소환 (`Q`, 25G)** : 일반(58%) ~ 전설(0.9% 직뽑 대박!) 확률 소환
   - **조합 (`W` 일괄 조합 / 유닛 더블클릭 / 드래그 합치기)** : 같은 성향 + 같은 등급 유닛 2기를 합쳐 다음 등급 랜덤 성향 1기로 확정 승급
   - **🎰 가스 도박 3종** : 가스를 걸고 희귀·에픽(65%), 유니크·전설(40%), **신화·태초 강림(20%)**에 도전하는 하이리스크 하이리턴 뽑기
   - **🌌 단독 태초 각성 (`T`)** : 신화(6등급) 유닛 1기 선택 후 140 가스를 소모해 **50% 확률로 태초(7등급) 각성** 도전 *(실패 시에도 신화 유닛은 증발하지 않고 보존!)*
   - **🔄 태초 계열 변환 (`T`)** : 태초 등급 유닛은 판매되지 않으며, 50 가스로 언제든 `⚡속사 → 💥폭발 → 🔮마도` 계열을 순환 변환하여 내가 집중 투자한 업그레이드 계열에 맞출 수 있습니다.

## 🎮 조작키 안내

| 입력 | 동작 |
| :--- | :--- |
| **좌클릭 (타일/유닛)** | 유닛 선택 · 선택 상태에서 다른 타일 클릭 시 **자리 이동 / 위치 스왑 / 동일 유닛 합치기** |
| **유닛 드래그 & 드롭** | 다른 타일로 드래그하여 자리 이동 / 스왑 / 합치기 |
| **유닛 더블클릭 / `C`** | 선택한 유닛과 동일한 짝이 있으면 즉시 상위 등급으로 조합 |
| **`Q`** | 랜덤 유닛 소환 (25 골드) |
| **`W`** | 보드 위 조합 가능한 중복 유닛(일반~전설) 일괄 조합 |
| **`E` / `Delete`** | 선택한 유닛 판매 (골드 & 가스 환급) |
| **`T`** | 선택한 신화 유닛 단독 태초 각성(50%) / 태초 유닛 계열 변환 |
| **`B`** | 현상금 미션 보스 호출 |
| **`G` / `X`** | 가스 광산 증설(`G`) / 100G → 45 가스 환전(`X`) |
| **`1` / `2` / `3`** | ⚡속사·진동(`1`) / 💥중포·폭발(`2`) / 🔮마도·관통(`3`) 공격력 강화 |
| **`Space` / `F`** | 게임 배속 전환 (`×1` → `×2` → `×3`) |
| **우클릭 드래그 / 휠** | 카메라 회전 및 줌 인·아웃 |
| **`P` / `Esc` / `M`** | 일시정지(`P`/`Esc`) / 전체 음소거(`M`) |
